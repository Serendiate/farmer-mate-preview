Farmer Mate · 農業地区レビュー

実りがつないだ街へ。

最初から遊ぶほか、収穫祭の直前まで進めた農園で、完成した街を確認できます。

農園を開く収穫祭直前の農園をダウンロード
  1. 農園を開き、メニュー → 記録・セーブへ。
  2. まず今の農園を書き出して残し、ダウンロードしたファイルを「記録から再開する」で選びます。
  3. 内容を確認して「この記録で再開する」。農園が確認用の記録に置き換わります。
  4. メニュー → 住民の物語・収穫祭 → 下の「広場へ歩く」。到着したら「ここで収穫祭を開く」を押してください。

各住民のカードには完結後の手紙、記録にはメインの会話が残っています。復興アルバムは、読み込んだ後の実際の景色から記録します。

確認用の記録は、新規農園から通常の移動・生産・売買で99項目を達成した通し検証の出力です。全設備を購入したデータではありません。
